{.glossary}
[REFEDS Multi-Factor Authentication (MFA) Profile](https://refeds.org/profile/mfa)
: Defines a standard signal to request MFA and to respond to such a
  request in a federated authentication transaction.  Also outlines
  requirements that an authentication event must meet in order to
  communicate the usage of MFA.  Supports both SAML 2.0 and OIDC.
